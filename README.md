Currency Converter Application

A simple and user-friendly currency converter built using Java and Swing. This application allows users to convert between CAD, USD, and AUD with ease.
Features

    Graphical User Interface (GUI): Built using Java Swing for an intuitive user experience.

    Currency Conversion: Supports conversion between CAD, USD, and AUD.

    Input Validation: Ensures users enter valid inputs for a smooth experience.

    Error Handling: Provides clear error messages for invalid inputs or operations.

    UI Components: Utilizes Swing components like JComboBox, JTextField, and JLabel for input and output.

Technologies Used

    Java

    Swing (GUI Toolkit)

    Object-Oriented Programming (OOP) Principles
